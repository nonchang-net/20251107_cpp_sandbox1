# 作業ログ 2025-12-05

## 変更内容の概要

スネークゲーム実装のバグを修正しました。C言語版から移植する際に発生した演算子優先順位の誤りにより、ビット配列の読み書き位置がずれていた問題を解決しました。`game/snake.cc` の `shift()` 関数に括弧を追加し、正しい計算順序に修正しました。

## 変更理由

C言語版のマクロ `SHIFT(x, y)` を関数化する際に、括弧が省略されたことで演算順序が変わってしまいました。元のマクロは `(((x) + ((y) * SNAKE_GAME_WIDTH)) * SNAKE_CELL_MAX_BITS)` でしたが、C++版では `x + y * SNAKE_GAME_WIDTH * SNAKE_CELL_MAX_BITS` となっており、乗算の結合順序の違いでビット位置が誤って計算されていました。この結果、foodの周辺に不正なブロックが生成され、蛇の移動時に意図しない衝突判定が発生していました。括弧を追加することで、C言語版と同じ計算ロジックを維持し、ゲームを正常に動作させました。

## 修正箇所

- `game/snake.cc:10` - `shift()` 関数の return 文に括弧を追加
  - 修正前: `return x + y * SNAKE_GAME_WIDTH * SNAKE_CELL_MAX_BITS;`
  - 修正後: `return (x + y * SNAKE_GAME_WIDTH) * SNAKE_CELL_MAX_BITS;`
